## Important Notes

### TestPyPi Credentials

If you need to reconfigure TestPyPi credentials:

1. Go to https://test.pypi.org/manage/account/
2. Create new API token if needed
3. Update `~/.pypirc`:
   ```ini
   [testpypi]
   repository = https://test.pypi.org/legacy/
   username = __token__
   password = pypi-test-YOUR-TOKEN-HERE
   ```
4. Set permissions: `chmod 600 ~/.pypirc`

### Virtual Environment

If virtual environment is not activated:
```bash
source venv/bin/activate  # macOS/Linux
```

### KIRO IDE

Make sure KIRO IDE is running and HiveForge project is open before starting Step 4.

## Troubleshooting Quick Reference

### Issue: Package upload fails
- **Check**: `~/.pypirc` credentials are correct
- **Check**: Token hasn't expired
- **Check**: Network connection

### Issue: Tests fail
- **Check**: Virtual environment is activated
- **Check**: Package installed correctly: `pip list | grep hiveforge`
- **Check**: Python version: `python --version` (requires 3.11+)

### Issue: KIRO IDE agents not working
- **Check**: KIRO IDE is running
- **Check**: Project is open in KIRO IDE
- **Check**: Agents are available in dropdown

### Issue: Steering files not generated
- **Check**: `.kiro/onboarding/` has Original Documents
- **Check**: Steering Assistant agent is selected
- **Check**: Prompt was submitted correctly
